# EasyImage 2.0 - 简单图床

一款基于 PHP 开发的开源图床程序，支持多文件上传、无数据库部署，可完美替代传统 PHP 多图上传工具。

## 主要特性

- **无数据库**: 纯文件存储，无需 MySQL 等数据库支持，部署简单
- **多文件上传**: 支持拖拽、粘贴、点击多种上传方式，单次最多 30 张
- **多种链接格式**: 上传后返回图片直链、Markdown、BBCode、HTML、缩略图等多种格式
- **自适应页面**: 基于 HTML5 的响应式设计，兼容手机与电脑端
- **图片处理**: 支持水印、压缩、缩略图生成、格式转换
- **API 支持**: 提供上传 API，方便第三方工具集成
- **多域名支持**: 可配置独立图片域名与访问域名
- **管理后台**: 内置管理员面板，支持文件管理、日志查看、统计图表
- **黑暗模式**: 支持一键切换明暗主题
- **上传历史**: 本地存储上传记录，方便回溯管理

## 技术栈

- **后端**: PHP 7.0+
- **前端**: ZUI 框架、jQuery、ECharts
- **图片处理**: Imagick / GD
- **文件管理**: TinyFileManager

## 安装部署

1. 将代码上传至支持 PHP 的 Web 服务器
2. 确保 `i/` 目录可写（用于存储上传的图片）
3. 访问 `install/` 目录完成安装向导
4. 安装完成后删除或重命名 `install/` 目录

## 环境要求

- PHP 7.0 或更高版本
- 开启 `fileinfo`、`gd` 或 `imagick` 扩展
- 足够的磁盘空间用于图片存储

## 配置说明

主要配置文件位于 `config/config.php`，可自定义：

- 站点标题、关键词、描述
- 上传限制（大小、数量、格式）
- 水印设置（文字/图片水印）
- 图片压缩与缩略图参数
- CDN 与多域名配置
- 登录与 API 开关

## 使用说明

1. 打开首页，选择或拖拽图片到上传区域
2. 点击「开始上传」或双击文件列表中的图片
3. 上传完成后在下方标签页切换所需的链接格式
4. 点击复制按钮即可获取对应格式的图片链接

## 注意事项

- 上传的图片默认存储在 `i/` 目录下，已加入 `.gitignore`
- 生产环境建议修改默认管理员密码
- 定期清理 `i/cache/` 目录以释放空间
- 若使用 FTP 同步，请确保 FTP 配置正确
