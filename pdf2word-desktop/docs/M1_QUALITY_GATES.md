## 1. 全书质量门禁唯一口径

全书不设置固定页数的前置或长期回归集合，也不生成可供后续任务复用的 PageModel、DOCX、PNG、CER 或视觉金标。每次正式任务必须从当前源 PDF、当前代码和严格指纹匹配的同一任务上下文运行，并以该次任务动态生成的抽样 manifest 作为唯一抽样门禁。预检从当前输入读取实际物理页数 `N`；抽样只决定高成本与人工复核范围，全部 `N` 页仍须执行自动硬门禁和最终渲染检查；完整流程以 `docs/FULL_BOOK_DYNAMIC_QUALITY_GATE.md` 为准。

仍然保留与具体固定页清单无关的通用检查：

- DOCX ZIP/OOXML 可读取；
- 可编辑文字数量；
- 原生 Word 段落、装饰图片和正文图片数量；
- 旧式 VML 正文文本框必须为零；
- Word/LibreOffice 能打开并导出；
- 渲染页数与源 PDF 物理页数一致；
- PageModel 静态冲突、覆盖率和回退报告；
- 源页与 Word 渲染图的区域级差异。

## 2. 已完成的 6 页样式与算法验收

物理页 7、8、9、10、21、23 是本书 source-first 改造的样式与算法验收样本，不是正式任务的固定抽样清单或可复用缓存。当前 v2 候选已经走完以下完整链路并获得用户确认：

```text
源 PDF → 水印清理 → 新渲染 → 新 OCR → 自动规则
→ PageModel → Word → 结构检查 → Word/LibreOffice 渲染 → 源页对照
```

这 6 页验证章节艺术标题、普通正文段落、选项、谈答案/解析/提示、分数与公式可编辑重建、标签去重和页码 `018`。紧凑分数必须输出为原生可编辑 OMML 上下式；“谈+标签”组合标识允许使用源图，但必须作为真实行内对象绑定后续可编辑正文，并核对其数量与宿主关系。题干、选项、答案、解析、提示、分数和公式的正文图片块必须为 0。后续页面按当前 v2 样式识别处理；正式任务仍只使用本次运行的源页证据和动态抽样 manifest，不读取该 6 页候选的 OCR、PageModel、DOCX 或人工修补工件。

## 3. 任意页数正式任务的动态抽样门禁

正式运行先对全部 `N` 页执行低成本普查，再在同一任务内根据页面类型、版式聚类、章节、重建模式和风险特征生成动态首批页。首批页通过后分批处理其余页面，每页均执行自动硬门禁；最终 DOCX 完成全书渲染后，还要把新发现的异常页追加到最终复核集合。

每次正式运行生成只属于该运行的抽样 manifest，至少包含：

1. 通用必选页：首个物理页、末页、检测到的封面和全部目录页；只有源指纹完整匹配时才附加书籍验收配置页，当前 381 页基准额外建议复核物理页 7、21、23；
2. 每种页面类型、章节和重建模式的确定性分层样本；
3. 所有整页回退页；
4. 所有图片/文字冲突、低置信度、公式碎片、溢出或异常重叠页；
5. 所有 CPU 回退页和自动修复升级页；
6. 源页与 Word 渲染差异超过预警阈值的页面。

抽样 manifest 必须记录源 PDF SHA-256、代码版本、PageModel schema、OCR 模型及权重哈希、参数、实际设备、选择算法版本、逐页选择原因和当前任务 ID。它是质量报告的一部分，不是下次运行可读取的 OCR/PageModel 缓存。动态集合不设最大页数；所有异常页必须纳入，具体 schema、停止条件和人工复核要求见 `docs/FULL_BOOK_DYNAMIC_QUALITY_GATE.md`。

## 4. 设备门禁

- 启动 OCR 前必须探测兼容计算设备；
- 兼容 NVIDIA GPU 可正常初始化时，版面分析、全页 OCR 和局部补 OCR必须使用 GPU；
- 显存不足时先降低批次、串行页面或缩小局部重试范围；
- 只有无兼容 GPU、初始化失败或降载后仍失败才允许 CPU；
- CPU 回退必须记录探测结果、失败原因、降载尝试和影响页码。

## 5. PageModel 静态门禁

每页写入 Word 前必须检查：

- 重复文字和主 OCR/补 OCR 重复；
- 文本块异常重叠、包含和阅读顺序；
- 图片与文字区域冲突；
- 公式或正文被输出为图片；
- 页码异常；
- 低置信度块；
- 原生段落可能换行或溢出；
- 回退块缺少来源、原因、等级或替代关系。

冲突消解和正文修复按局部补 OCR、字符归一化、段落重组和有源指纹约束的可编辑文字修复逐级升级。无法确认时本次候选失败，不得将词组、公式、单行、语义区域、单题或整页正文改为图片。

## 6. 可编辑性与 DOCX 结构门禁

- 普通题目页可靠正文的可编辑字符覆盖率不低于 85%；
- 章节首页仅排除 Logo、艺术标题、“谈+标签”组合标识、侧栏、艺术页码和真实图形后，可编辑正文覆盖率不低于 80%；
- 目录文字全部可编辑；
- 公式重页的正文、分数和公式必须可编辑；
- 普通正文不得写入旧式 VML 逐行文本框；
- Word 中的正文必须能实际选中、复制和修改；
- 每页 `body_image_blocks` 必须为 0，图片只允许属于明确的装饰/真实图形白名单；
- 普通题目页整页截图必须列为异常。

可编辑覆盖率阈值必须由版本化质量策略提供并写入报告，不能散落在报告或页面处理函数中。当前 6 页历史候选使用 `editable_pilot_coverage_v1`；未来正式入口使用未知内容默认不放行的 `strict_full_document_coverage_v1`。

通用命令必须把预检得到的实际 `N` 传给 `--expected-pages`。以下只示范当前 `N = 381` 的大型基准：

```powershell
pdf2word-engine docx-check .\outputs\candidate.docx `
  --minimum-editable-characters 100 `
  --render-output-dir .\runtime\docx-check --expected-pages 381
```

## 7. OCR 准确率与人工真值

字符错误率仍是有价值的算法指标，但旧 CER JSON 以旧 PageModel block ID 为锚点，已经失效，因此一并删除。以后如重建人工真值集，必须以“源 PDF 哈希 + 物理页码 + 稳定源区域坐标 + 人工转写”作为主键，生产 OCR 只能做预填草稿，不能作为真值，也不能与任务缓存混放。

当前输入的 `N` 页验收不因缺少新的人工真值集而伪报 CER 通过；质量状态应明确写为“CER 尚未建立”或给出实际已审校范围。当前大型基准的 `N` 为 381。

## 8. 渲染和兼容性门禁

LibreOffice 用于开发期快速回归；Microsoft Word 是最终分页和打开能力门禁；WPS 单独记录兼容性，不替代 Word。

每次候选 DOCX 至少检查：

- 页面数量、尺寸、顺序和分页；
- 黑块、乱码、裁剪、重叠、溢出和异常空隙；
- 图片与文字冲突为零；
- 分数和公式的文字准确性、可编辑性及排版；
- 目录点引导线、书签和可编辑文字；
- 可编辑字符覆盖率、正文图片块、装饰图片率和整页截图率；
- 当前源页与当前 Word 渲染的区域级差异。

Microsoft Word 实机命令同样必须使用预检得到的实际 `N`。以下只示范当前 `N = 381` 的大型基准：

```powershell
pdf2word-engine word-render-check .\outputs\candidate.docx `
  --output-pdf .\runtime\word-check\candidate.pdf --expected-pages 381
```

## 9. 状态与报告门禁

质量报告必须区分：

- `conversion_completed`：指定页面已生成，不代表质量通过；
- `static_quality_passed`：PageModel 静态门禁通过；
- `full_book_render_completed`：最终 DOCX 已渲染为预检得到的 `N` 页并完成全量自动检查；
- `current_run_e2e_passed`：本次动态抽样完整链路通过；
- `full_book_quality_passed`：全部 `N` 页静态检查、动态抽样、全书渲染和报告均通过。

正式任务报告至少包含冲突页、低置信度页、正文图片失败页、所有装饰/真实图形图片清单、可编辑覆盖率、自动修复、实际设备、CPU 回退、动态抽样页、人工抽检页及源页/Word 渲染差异。
